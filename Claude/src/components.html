Shell rules
  • Sidebar is charcoal so blue stays reserved for actions; active item = light tint + left indicator.
  • Top bar always shows the connection pill, alerts bell with count, role badge and avatar (NFR security).
  • Admin shows a lock for non-admin roles instead of disappearing, so permissions are explained.
  • Tablet replaces the sidebar with the charcoal top bar and print tabs (section 9).
